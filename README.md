# 🎮 C++ Maze Game

A simple console-based Maze Game developed using **C++** as my **1st Semester Programming Fundamentals Project**.

The objective of this game is to navigate the player (`P`) through a maze, avoid walls, and reach the exit (`E`) to win the game.

## 📌 Project Overview

This project is a beginner-level C++ game that demonstrates fundamental programming concepts through an interactive maze.

The game runs in the Windows console and allows players to move through the maze using keyboard controls without pressing Enter.

## ✨ Features

- 🟢 Player movement using W, A, S, D keys.
- 🧱 Walls that block the player's movement.
- 🏁 Exit point to complete the maze.
- 🎨 Colored console output for better visualization.
- ⚡ Real-time keyboard input without pressing Enter.
- 🏆 Winning message when the player reaches the exit.
- ❌ Quit option to exit the game.

## 🎮 Controls

| Key | Action |
|---|---|
| W | Move Up |
| S | Move Down |
| A | Move Left |
| D | Move Right |
| Q | Quit Game |

## 🧩 Maze Symbols

| Symbol | Meaning |
|---|---|
| P | Player |
| # | Wall |
| . | Empty Path |
| E | Exit |

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project in a C++ IDE (such as Dev-C++ or Code::Blocks).
3. Compile and run the source code.
4. Use W, A, S, D to navigate through the maze.
5. Reach `E` to win!

### Compile using g++

```bash
g++ main.cpp -o MazeGame
```

Run the game:

```bash
MazeGame.exe
```

**Note:** This project uses Windows-specific libraries and console functions, so it is designed to run on Windows.
